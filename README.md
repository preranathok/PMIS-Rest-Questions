# PMIS REST API Questions

## Project Overview
This project contains six Spring Boot REST API practice questions.

## Features
1. Get All Products
2. Get Product By ID
3. Create Product
4. Update Product
5. Delete Product
6. Search Books by Title and Author

## Technologies
- Java
- Spring Boot
- Maven
- REST API
- Postman

## Testing
All six API endpoints were tested locally using Postman.
